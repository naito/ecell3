Detailed Description

Model class represents a simulation model.

Model has a list of Steppers and a pointer to the root system.

◆ initialize()

void libecs::Model::initialize ( )

Initialize the whole model.

This method must be called before running the model, and when structure of the model is changed.

Procedure of the initialization is as follows:

  1. Initialize Systems recursively starting from theRootSystem. ( System::initialize() )
  2. Check if all the Systems have a Stepper each.
  3. Initialize Steppers. ( Stepper::initialize() )
  4. Construct Stepper interdependency graph ( Stepper::updateDependentStepperVector() )

InitializationFailed
